# React Project Manager Lab — прогресс обучения

## Цель проекта

Изучить React от базовых компонентов до архитектуры production-приложения на практике, создавая менеджер проектов и задач на React, TypeScript, Vite, pnpm и styled-components.

## Формат обучения

Каждый урок проходит по схеме:

1. Теория.
2. Конспект от руки.
3. Практическое задание.
4. Проверка кода.
5. Исправление ошибок.
6. Проверка знаний.
7. ESLint и production build.
8. Коммит и push учебной ветки.
9. Объединение завершённого урока с `main`.
10. Обновление этого файла.

## Как продолжить после перерыва

1. Открыть репозиторий.
2. Прочитать этот файл.
3. Проверить текущую ветку:

   `git branch --show-current`

4. Получить изменения:

   `git pull`

5. Установить зависимости при необходимости:

   `pnpm install`

6. Запустить проект:

   `pnpm dev`

7. Отправить ассистенту ссылку на репозиторий и вывод:

   `git log -1 --oneline`

## Правило обновления прогресса

После каждого урока необходимо:

- перенести урок в раздел завершённых;
- записать ветку, commit и merge-коммит;
- обновить количество завершённых уроков и процент;
- указать следующий урок;
- сохранить результаты ESLint и production build;
- закоммитить и отправить обновление на GitHub.
